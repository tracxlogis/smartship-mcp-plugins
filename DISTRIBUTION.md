# Distribution notes / 배포 안내

**English** | [한국어](#한국어-1)

This repository is the **public distribution copy** for SmartShip sellers. The source of truth is the
`mcp-marketplace/` directory inside the internal `tx-front-react` repository; skills and manifests are
edited there and synced here, so that a change to the MCP tool registry and the skills that describe it
always land in the same commit.

- Install instructions for users: see [README.md](README.md).
- Guide and detailed usage: <https://smartship2.tracxlogis.com/services/smartship-mcp>
- Issues with the plugin content are handled by the TracX SmartShip team through the guide page above.

Please do not open pull requests against this repository — changes made here would be overwritten by
the next sync from the source of truth.

---

## 한국어

[English](#distribution-notes--배포-안내) | **한국어**

이 저장소는 SmartShip 셀러용 **공개 배포본**이다. 정본은 사내 `tx-front-react` 저장소의
`mcp-marketplace/` 디렉터리이며, 스킬·매니페스트는 그쪽에서 고쳐 이곳으로 동기화한다 — MCP 도구
레지스트리 변경과 그 도구를 설명하는 스킬이 항상 같은 커밋에 들어가게 하기 위해서다.

- 사용자 설치 방법: [README.md](README.md) 참고.
- 연결 가이드와 자세한 사용법: <https://smartship2.tracxlogis.com/services/smartship-mcp>
- 플러그인 내용 관련 문의는 위 가이드 페이지를 통해 TracX SmartShip 팀이 처리한다.

이 저장소로 직접 Pull Request 를 보내지 않는다 — 다음 동기화 때 정본 내용으로 덮어써진다.
